Browser-Based Ergonomic Posture Assessment Tool

Posture Assessment Interface

Project Overview

Real-Time Computer Vision-Based Ergonomic Assessment

Objective:

Build a browser-based ergonomic posture assessment tool that scores seated desk posture in real time using computer vision.

Key Features:

  • Real-time Pose Estimation: Live webcam processing with 17-point body keypoint tracking
  • Personalized Calibration: Scores measured against user's own baseline posture, not fixed universal thresholds
  • Multi-Joint Scoring: Evaluates neck alignment, shoulder symmetry, and elbow angle with weighted overall score
  • Guideline-Referenced: Elbow angle validated against OSHA/NIOSH desk-posture guidelines (90°–120° range)
  • Confidence Filtering: Temporally smoothed readings prevent noisy single-frame detection errors
  • Live Dashboard: Custom web interface with real-time score gauge and per-metric breakdown

Technical Architecture:

Flask backend serving a custom web interface with live score visualization

Data Privacy:

Live webcam video processed locally — no external datasets, no stored video, no data transmission. All inference runs on-device.

Impact:

End-to-end computer vision pipeline demonstrating pose detection to defensible scoring system. Positioned as automated alternative to manual ergonomic assessments (DSE workstation reviews).

Tools & Technologies:

Python, Ultralytics YOLO26-Pose, OpenCV, Flask, NumPy, HTML/CSS/JavaScript
