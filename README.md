## 🚀 Getting Started

### Local Development

1. **Clone the repository**
   ```bash
   git clone https://github.com/AlenChristopher/portfolio.git
   cd portfolio
   ```

2. **Open in browser**
   - Simply double-click `index.html`
   - Or use a local server:
   ```bash
   python -m http.server 8000
   # Then visit http://localhost:8000
   ```

### Deploy to Netlify

1. Go to [Netlify](https://netlify.com)
2. Sign up for a free account
3. Click "New site from Git"
4. Connect your GitHub repository
5. Deploy! 🚀

**Or drag & drop:**
1. Go to https://netlify.com/drop
2. Drag your project folder
3. Instant deployment!

### Deploy to GitHub Pages

1. Push to GitHub
2. Go to repository Settings → Pages
3. Select main branch as source
4. Your site goes live at `username.github.io/portfolio`

## 📝 Customization

### Update Personal Information

Edit `index.html` to add your:
- Hero image: `img/hero/hero.png`
- Project images: `img/works/01.jpg` - `06.jpg`
- Social links
- Contact information

### Modify Content

All text content is directly in `index.html`. Simply search and replace:
- Your name
- Your title/tagline
- About section text
- Experience details
- Education details
- Certifications

### Change Colors

Edit color variables in `css/main.css`:
```css
:root {
  --primary-accent: #0c1618;      /* Main color */
  --secondary-accent: #6f1d1b;    /* Accent color */
  /* ...more colors */
}
```
